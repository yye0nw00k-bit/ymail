# yeole 국어사전 기능

Ymail에 기존 로그인 세션을 사용하는 국어사전 화면과 API를 추가합니다.

- 관리자 계정이 등록한 항목은 공식 단어로 저장됩니다.
- 일반 계정이 등록한 항목은 비공식 오픈사전으로 저장됩니다.
- 검색, 품사/예문 표시, 작성자별 삭제, 관리자 승격을 지원합니다.
- 사전 항목은 `data/dictionary.json`에 저장됩니다.

주의: 현재 Ymail은 사용자/메일/채팅 데이터를 JSON 파일로 저장합니다. Render 재배포나 인스턴스 교체 후에도 데이터가 보존되어야 한다면 Persistent Disk를 연결하고 `data` 경로를 영구 저장소에 마운트해야 합니다. `data/dictionary.json`은 기존 데이터 파일과 분리되어 있습니다.
